<h2 align="center">Beta 10 — dez devs, projetos reais, evidências reais</h2>

A Retoma é uma ferramenta de continuidade operacional para desenvolvimento de software. Ela registra onde o trabalho parou, quais decisões foram tomadas, quais riscos existem e qual é o próximo passo acionável.

Estamos selecionando **dez desenvolvedores** para uma validação privada em projetos reais.

## Procuramos pessoas que

- desenvolvam ou estejam aprendendo a desenvolver;
- tenham um projeto ativo para usar durante o teste;
- possam realizar pelo menos duas sessões em dias diferentes;
- aceitem registrar feedback objetivo pelo GitHub;
- não compartilhem o código privado recebido durante o programa.

Experiência avançada não é obrigatória. Queremos especialmente entender onde a desorientação operacional aparece para quem está começando.

## Como participar

1. Abra uma candidatura em **Issues**.
2. Responda somente às perguntas do formulário.
3. Não publique e-mail, telefone, token, senha ou código privado.
4. Os selecionados receberão um convite oficial do GitHub para a organização `Retoma-labs`.

[Quero me candidatar](https://github.com/Retoma-labs/beta/issues/new?template=candidatura.yml)

## O que será avaliado

- instalação sem assistência;
- clareza do estado capturado;
- retomada do projeto após pelo menos 24 horas;
- utilidade do próximo passo sugerido;
- erros, bloqueios e intenção de continuar usando.

O acesso é gratuito, individual, temporário e limitado ao programa de validação.
